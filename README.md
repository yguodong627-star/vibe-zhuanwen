# 转文 · 文本与数据清洗

把常用的文本清洗动作串成一条**规则链**，一次处理完；再顺手把 CSV / JSON / Markdown 表格互转。纯前端，打开即用，**数据不会离开你的浏览器**。

在线使用：https://yguodong627-star.github.io/vibe-zhuanwen/

## 适合谁、解决什么
- 运营、客服、行政、产品：从表格、群消息、网页里拷出一堆脏文本，要去空行、去重、统一格式。
- 排版：中英文之间补空格、全半角统一、中英文标点统一。
- 抽数据：从一大段文字里取出邮箱、链接、手机号。
- 表格：Excel 复制出来的内容转成 JSON / Markdown 贴到文档或接口里，反过来也行。

和“一个功能一个页面”的在线小工具不同：这里的规则可以**勾选、排序、组合并保存**，下次一键套用；改完能看到**逐行差异**，也能看每条规则增减了多少行。

## 功能
清洗规则（可任意组合，顺序可调）：
去首尾空格 · 合并连续空格 · 去空行（全部删除/连续合并）· 全角/半角转换 · 统一标点（中⇄英）· 中英文间加/去空格 · 批量查找替换（可正则，`旧 => 新`，支持 `$1`）· 提取邮箱/链接/手机号 · 按分隔符拆列/取某列/拆成多行 · 去重行 · 排序（拼音/降序/长度/数字/倒序/随机）

其他：
- CSV / TSV（含从 Excel 直接粘贴）/ JSON / Markdown 表格互转，自动识别格式与分隔符，支持引号、换行、嵌套 JSON 拍平
- 输入与输出的差异预览（行级 + 行内高亮）
- 一键复制、下载、“用作输入”继续下一轮处理
- 手机与电脑自适应；跟随系统深色模式

## 完全免费
没有任何功能锁和用量限制：全部规则、表格互转、差异预览、复制都能用；规则链可以保存任意多条，支持导入 / 导出；批量多文件处理可直接使用；文本长度不设上限（只受浏览器内存限制）。数据不上传。

## 隐私
没有后端，没有统计，没有网络请求（自测里断言了页面不发出任何外部请求）。规则链保存在浏览器 localStorage，输入的文本不保存。

## 本地运行 / 自测
直接打开 `index.html` 即可。自测（84 项，覆盖每条规则、各格式互转、规则链不限数量、导入导出、批量、无上限）：

```
npm i puppeteer-core   # 并确保本机有 Chrome，按需修改 test.js 里的路径
node test.js
```

## 已知限制
- “统一标点”按相邻汉字判断，不处理单引号；中英混排的极端写法可能判断不准。
- “中英文间加空格”不识别网址/代码，URL 里夹汉字时也会被加空格。
- 差异预览是行级；文本很大（变化超过约 400 万次比较）时退化为近似比较。
- 批量文件逐个下载，没有打包 zip；文件按 UTF-8 读取。
- 手机号只识别中国大陆 11 位号码。
